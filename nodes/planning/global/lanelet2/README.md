# Global planning


## lanelet2_global_planner

A ROS node that implements a global planner for autonomous vehicles based on Lanelet2 map. The node subscribes to the `move_base_simple/goal` topic and publishes the global path as a sequence of waypoints to the `lanelet2_global_path` topic. The node uses the current position of the vehicle from the `localization/current_pose` topic and generates the global path to the goal position by finding the shortest path in the Lanelet2 map.


#### Parameters

| Name | Type | Default Value | Description                                                                                 |
|------|------|---------|---------------------------------------------------------------------------------------------|
| `~lanelet2_map_path` | string | `-` | Path to the Lanelet2 map file                                                               |
| `~distance_to_centerline_limit` | float | `5.0` | The maximum distance from the centerline for a waypoint on the generated path (m)           |
| `~lane_change` | bool | `False` | Whether to allow lane changes during route planning                                         |
| `~lanelet_search_radius` | float | `0.5` | Radius for searching lanelets around a point (m)                                            |
| `~routing_cost` | string | `travel_time` | Routing cost function to use (`distance` or `travel_time`)                                  |
| `output_frame` | string | `map` | The name of the output frame for the generated path                                         |
| `distance_to_goal_limit` | float | `5.0` | The minimum distance from the last waypoint to the goal position for the generated path (m) |
| `speed_limit` | float | `50.0` | The speed limit for the generated path (km/h)                                               |
| `ego_vehicle_stopped_speed_limit` | float | `0.1` | Below this speed limit ego vehicle is considered as stopped (m/s)                           |
| `lane_change_base_length` | float | `10.0` | Base length for lane change maneuvers (m)                                                   |
| `lane_change_perlane_length` | float | `5.0` | Additional length per lane for lane change maneuvers (m)                                    |
| `waypoint_interval` | float | `1.0` | Interval between waypoints (m)                                                              |


#### Subscribed Topics

| Name | Type | Description |
|------|------|-------------|
| `/localization/current_pose` | `geometry_msgs/PoseStamped` | The current position of the ego vehicle |
| `/localization/current_velocity` | `geometry_msgs/TwistStamped` | The current velocity of the ego vehicle |
| `/move_base_simple/goal` | `geometry_msgs/PoseStamped` | The goal position of the vehicle |


#### Published Topics

| Name | Type | Description |
|------|------|-------------|
| `lanelet2_global_path` | `autoware_mini/Path` | The generated global path |
| `target_lane_markers` | `visualization_msgs/MarkerArray` | The markers for the target lane (mainly for debugging purpose) |



## lane_change_planner

ROS node that generates a path for lane change maneuvers based on the global path provided by the global planner. It replaces lane change waypoints with a smooth Bezier curve transition between lanes.


#### Parameters

| Name | Type | Default Value | Description |
|------|------|---------|-------------|
| `waypoint_interval` | float | `1.0` | Interval between waypoints (m) |
| `lane_change_base_length` | float | `10.0` | Base length for lane change maneuvers (m) |
| `lane_change_perlane_length` | float | `5.0` | Additional length per lane for lane change maneuvers (m) |


#### Subscribed Topics

| Name | Type | Description |
|------|------|-------------|
| `lanelet2_global_path` | `autoware_mini/Path` | The global path generated by the global planner |


#### Published Topics

| Name | Type | Description |
|------|------|-------------|
| `lane_change_global_path` | `autoware_mini/Path` | The global path with lane change segments replaced by smooth transitions |



## lanelet2_map_visualizer

ROS node for visualizing Lanelet2 map elements including road boundaries, centerlines, traffic lights, stop lines, and crosswalks. It can operate in two modes: full map visualization or extraction of relevant map elements around the ego vehicle.


#### Parameters

| Name | Type | Default Value | Description |
|------|------|---------|-------------|
| `~lanelet2_map_path` | string | `-` | Path to the Lanelet2 map file |
| `~enable_auto_stop_checker` | bool | `-` | Whether to enable the automatic stop checker functionality |
| `~use_map_extraction` | bool | `False` | Extract smaller map area around the ego vehicle for visualization |
| `~map_extraction_distance` | float | `500` | Distance from ego vehicle to extract map data (m) |
| `local_path_length` | float | `100` | Length of the local path (m) |


#### Subscribed Topics

| Name | Type | Description |
|------|------|-------------|
| `/detection/traffic_light_status` | `autoware_mini/TrafficLightResultArray` | Status of traffic lights |
| `/planning/lets_go` | `std_msgs/Int32` | Signal to proceed at yield stop lines |
| `/localization/current_pose` | `geometry_msgs/PoseStamped` | The current position of the ego vehicle (when use_map_extraction is true) |


#### Published Topics

| Name | Type | Description |
|------|------|-------------|
| `tfl_stop_line_markers` | `visualization_msgs/MarkerArray` | Markers for traffic light stop lines |
| `yield_stop_line_markers` | `visualization_msgs/MarkerArray` | Markers for yield stop lines |
| `lanelet2_map_markers` | `visualization_msgs/MarkerArray` | Markers for all map elements |
